## ✦ What this is
FinFlow is a complete multi-entity financial management platform with:
- 25 modules: GL, P&L, Balance Sheet, AR/AP, Sales, FX, Budget, Cash Flow
- P2P Suite: Vendor Master, PR, PO, Goods Receipt, Supplier Invoice (3-way match), Payment Run

- Reporting: Fixed Assets, Headcount & Payroll, Report Pack, AI Finance Manager

## Deploy to Vercel from GitHub (step by step)

### Step 1 — Push this folder to GitHub
1. Go to **github.com** and sign in
2. Click **New repository** (top right, green button)
3. Name it: `finflow` — set to **Public** — click **Create repository**
4. On the next page, click **uploading an existing file**
5. Drag ALL files from this folder into the upload area
6. Scroll down, click **Commit changes**

### Step 2 — Connect GitHub to Vercel
1. Go to **vercel.com** and sign in
2. Click **Add New Project** (top right)
3. Click **Continue with GitHub** → select the `finflow` repository
4. Vercel auto-detects Vite. You'll see:
   - Framework Preset: **Vite** ✓
   - Build Command: `npm run build` ✓
   - Output Directory: `dist` ✓
5. Click **Deploy** — takes about 90 seconds

### Step 3 — Get your URL
- Vercel gives you a URL like: `https://finflow-abc123.vercel.app`
- That's your live FinFlow — share it with clients

### Updating in future
- Edit any file in GitHub → commit → Vercel auto-redeploys in ~60 seconds
